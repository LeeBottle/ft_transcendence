# GitHub 프로필 및 닉네임 옆 표기 설정 가이드

GitHub 닉네임 옆에 표시되는 문구나 뱃지는 설정 목적에 따라 3가지가 있습니다:

---

### 1. 표시 이름(Display Name) 설정 (예: `phonyvif (Sanghul Lee)`)
아이디(`phonyvif`) 옆에 가로 또는 밑에 실제 이름이나 닉네임을 크게 띄우는 기능입니다.

* **설정 방법**: 
  1. GitHub 오른쪽 상단 프로필 클릭 ➔ **`Edit profile`** (또는 `Settings` ➔ `Public profile`)
  2. **`Name`** 칸에 표시하고 싶은 이름(예: `Sanghul Lee` 또는 `Antigravity`) 입력 후 Save

---

### 2. 프로필 커스텀 상태 메시지(Status) 설정 (예: `💻 Coding...`, `🌴 휴가중`)
닉네임 바로 옆에 이모지와 한 줄 상태 메시지를 띄우는 기능입니다.

* **설정 방법**: 
  1. GitHub 오른쪽 상단 본인 프로필 사진 클릭
  2. 메뉴 상단의 **`Set status`** 클릭
  3. 이모지 선택 및 원하는 상태 문구 작성 후 Save

---

### 3. 소속 조직(Organization) 및 역할 뱃지 (예: `Member`, `Owner`, `Contributor`)
저장소나 팀 소속을 나타내는 뱃지입니다.

* **Repository / PR 뱃지**: 
  * `Owner`: 저장소 관리자
  * `Contributor`: 기여자
  * `Member`: 해당 깃허브 조직(Org) 소속 멤버
* **조직 뱃지 표시 설정**: 
  * GitHub `Settings` ➔ **`Organizations`** ➔ 소속 조직의 공개 여부를 **`Public`**으로 설정하면 프로필 옆에 소속 아이콘이 뜹니다.
